    Как считаются коэффициенты

    Обозначения: Д — доходы за месяц, Р — расходы за месяц, Ро — обязательные траты (продукты, жильё, транспорт, связь, здоровье, учёба), Рн — остальные, Б — бюджет месяца, d — прошедшие дни месяца, N — дней в месяце, Н — накопления. Все суммы в выбранной валюте.

    • Норма сбережений = (Д − Р) / Д. Ориентир 20 % и выше, по правилу 50/30/20 (Э. Уоррен, А. Уоррен-Тьяги, «All Your Worth», 2005).
    • Коэффициент трат = Р / Д. Больше 1 — тратите больше, чем зарабатываете.
    • Обязательные / доход = Ро / Д, ориентир до 50 %. Необязательные / доход = Рн / Д, ориентир до 30 %.
    • Темп трат = (Р / d) / (Б / N). 1,0 — идёте ровно по бюджету, 1,2 — тратите на 20 % быстрее плана.
    • Прогноз на месяц = Р / d × N — если тратить дальше в том же темпе.
    • Финансовая подушка = Н / средние расходы за 3 прошлых месяца, в месяцах. Распространённый ориентир — 3–6 месяцев.

    Пример: Д = 80 000, Р = 62 000. Норма сбережений = (80 000 − 62 000) / 80 000 = 0,225 = 22,5 %; коэффициент трат = 62 000 / 80 000 = 0,775.
